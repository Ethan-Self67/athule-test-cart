# Athule-Test-Cart
Project Overview:
Electronic components required to test experimental/production blades to maximize efficiency and minimize sound. Made for mobile and realistic airflow testing purposes in non-perfect weather environments. The test cart allows for a 50V or 100V test set up. These can be swapped between by just changing 4 wires to connect the second battery. This Test Cart is used on the "medium test stand" or specifically the Tyto 1780 Thrust Stand, only for 50V. Both the 50V and 100V can be used on the "large test stand" or specifically the Tyto Robotics Flight Stand 50, this test stand is also the one that is brought outside for more realistic testing scenarios. This cart exists to make the task of switching between test stands to be easier while also allowing for a mobile variant for outdoor testing. There is also a section of circuit breakers connected in parallel that allow for the test cart to be easily accessible when testing indoors. The circuit breakers being connected in parallel work by allowing the electricity to flow when one set of circuit breakers are turned on and allowing the physical locations of those circuit breakers to be closer to the test stand.

My Role:
I was the project lead. So I figured out how the wires were going to be connected in the cart and how the cart was going to be built. After figuring out connections between electrical components and making the cart, I modeled the cart in Onshape, then made the physical connections of wires. After testing different spots in the cart for the correct voltage readings I worked on getting temperature readings of the cart after extended use. I also worked on testing the blades once the test cart was finished.

Design Process:
The whole project needed to be completed in about 3 weeks because the Athule clients needed the blades that we were making, and we had to test the blades before shipping them out. When starting with making the box a lot of the costs for the box came from the wood, since we already had the electronic components, so we tried to use the wood as much as possible. Also coming up with a lot of the cooling systems for the box was a big deal. We decided on sealing the edges of the box and putting fans on either end to make a convection of pushing in cold air and bringing out the hot air. This was mainly for the bottom section of the cart because each of the 50V lithium iron phosphate batteries produce a lot of heat when being used, especially in an enclosed environment. The pneumatic tires we used for the cart was also a very important detail because it would allow for the cart to be moved in different outside environments a lot easier, as apposed to normal casters that would not adapt to different terrain well. Overall. a lot of the detail were thought of when creating the test cart but I still think there could have been a lot more optimization of space and cooling if there was more time to spend on the specifications. 

Challenges & Solutions:
One of the biggest problems we faced when making the test cart was getting the parallel circuit breakers to work. This was because the electromagnetic fields that the wires produce were interfering with the data signals of other wires. Since the wires were in such a close proximity of one another we had to worry about giving enough room between wires for each electromagnetic field to have its own pulse. Since the parallel circuit breaker wires are only used inside, we were able to 3D print spacers so we could separate the wires enough for the data to be collected. This was a very interesting problem to me, because who thinks that could even be a problem? So finding the source of the problem in the first place was tricky, but once we realized the problem we were able to come up with a solution that integrates really well with the test cart.

Outcome:
In the end, we were able to finish the box in the 3 week requirement and start testing blades by the time the internship was coming to a close. I was pretty happy with how the cart turned out even though I think there were come places where we could have optimized the cart more. Such as the convection fans and how much space the cart took up. Overall, I learned a lot about aviation electronic components and making sure that every detail is thought through before committing.
